Entrada MIDI

Toque em Conectar MIDI.

O Cycles não aparece ou não manda nada?
  1. Use o Chrome ou o Edge (Safari e Firefox não servem) e aceite o pedido de MIDI. Se recusou: cadeado ao lado do endereço → MIDI → Permitir.
  2. No Cycles: Settings → MIDI Config → Port Config: Output to = USB (ou MIDI+USB) e Output CC/NRPN ligado. Em Sync, Clock send ligado. Em Channels, as trilhas nos canais 1–6.
  3. Dê play no Cycles: a porta dele tem que ficar "recebendo ●" aqui em cima.
  4. Windows + Ableton aberto: o Windows só deixa um programa por vez abrir o aparelho. Feche o Ableton, ou desligue Track/Sync/Remote do Cycles nas preferências MIDI dele, ou use o loopMIDI pra repassar.
  5. Cabo USB de dados (não só de carga) e, se usar hub, teste direto no computador.

Se a imagem vier antes do som (caixa Bluetooth), puxe pra esquerda; se vier depois, pra direita.

Parâmetros (CC)

Toque em Aprender e mexa no knob correspondente do Cycles. Para o Cycles mandar os knobs, ligue MIDI Config → Port Config → Output CC/NRPN.
